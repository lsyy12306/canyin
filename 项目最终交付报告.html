五、如何运行与部署

本地开发与容器化生产两套路径。

本地预览原型
打开 prototype.html（已起本地服务：http://127.0.0.1:8123/prototype.html）
后端启动
cd backend && uvicorn main:app --reload --port 8000（接口根 /api，健康 /api/public/health）
前台启动
cd frontend && npm install && npm run dev（默认 :5173）
后台启动
cd admin && npm install && npm run dev（默认 :5174）
容器部署
docker compose up -d → 前台 :80 / 后台 :8080 / 后端 :8000
后台账号
admin / admin123456（首登必须修改）
